# 🚀 AI Proxy Router

Автоматическая маршрутизация трафика популярных AI-сервисов через SOCKS5-прокси на серверах с **3x-ui (VLESS/Xray)** и **Amnezia VPN (AmneziaWG/WireGuard)**.

Решает проблему блокировок и региональных ограничений (*"Страна не поддерживается"*, GeoIP `"GL":"RU"`) на VPS в Нидерландах, Германии, Финляндии и у других хостеров. Через ваш прокси направляется **только трафик нейросетей**, весь остальной интернет и YouTube работают напрямую на максимальной скорости.

---

## ⚡ Быстрый старт

Запустите команду на вашем сервере (от имени `root`):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/pylcov/ai-proxy-router/main/setup-ai-proxy.sh)
```

> 💡 **Всё включено:** Скрипт сам проверит окружение, при необходимости установит недостающие пакеты (`python3`, `jq`, `dnsutils`, `ipset`, `iptables`, `sing-box`) и всё настроит. Данные прокси можно вставить одной строкой (`IP:PORT:USER:PASS`) или ввести по шагам.

## ⚙️ Как это работает

### 1. Выборочная маршрутизация
Скрипт позволяет гибко выбрать, что именно направлять в прокси:
- **Все AI-сервисы разом**;
- **Только отдельные платформы** (например, только Gemini или только ChatGPT + Claude);
- **Ручной выбор** любой комбинации через запятую.

### 2. 📺 Умная маршрутизация YouTube (без лагов и буферизации)
Обычные решения «завернуть весь Google в прокси» приводят к тому, что YouTube начинает крутить иностранную рекламу (польскую, немецкую и т.д.), а 4K-видео тормозит через узкий канал прокси.
В **AI Proxy Router** эта проблема решена:
- **В 3x-ui (Xray)**: Добавляется приоритетное правило маршрутизации `geosite:youtube` и всех CDN-доменов Google Video → `direct` перед правилами AI.
- **В Amnezia VPN**: Используется современный `sing-box` с TLS SNI-сниффингом. Он на лету определяет все домены YouTube (`youtube.com`, `googlevideo.com`, `youtu.be`, `ytimg.com`, `gvt1.com` и др.) и направляет их напрямую через сервер на максимальной скорости 4K/8K, в то время как Gemini, Antigravity и служебные бэкенды Google идут в прокси.

### 3. 3x-ui (VLESS / Xray)
- Напрямую модифицирует базу `/etc/x-ui/x-ui.db` без необходимости ручной настройки в браузере.
- Создает исходящее подключение `ai-proxy` со стратегией `UseIPv4`.
- Формирует точечные правила маршрутизации (Routing Rules) для выбранных AI-доменов и IP-подсетей.
- Блокирует QUIC (UDP 443) для нейросетей, заставляя клиентские приложения работать через TCP-прокси без утечки реального IP.

### 4. Amnezia VPN
- Поддерживает любые контейнеры AmneziaWG (версий 1.0, 2.0 и 3.0).
- Направляет трафик к IP-подсетям нейросетей через связку `sing-box` + `ipset` + `iptables`.
- Использует **атомарное обновление ipset** (`swap`), исключая обрывы соединений и даунтайм при перезапуске.
- Регистрирует `systemd`-сервисы (`sing-box.service` и `amnezia-ai-proxy.service`), гарантируя надежный автозапуск после перезагрузки сервера.

### 5. Консольные утилиты на сервере
Скрипт поднимает локальный порт **`127.0.0.1:2080`** (SOCKS5/HTTP) и прописывает алиасы в `~/.bashrc`:
- `agy`, `claude`, `codex`, `gemini`, `opencode`, `aider`, `cursor`.

Также добавляется универсальная функция **`proxyrun`**, позволяющая выполнить **любую команду** через прокси:
```bash
proxyrun opencode
proxyrun python script.py
proxyrun npm start
```

### 6. 🔍 Диагностика регионов нейросетей
Скрипт включает встроенный тест доступности через прокси:
- **Google / Gemini**: проверяет региональный тег `GL` и шлёт проверочный запрос в Gemini API (`generativelanguage.googleapis.com`);
- **OpenAI / ChatGPT**: проверяет Cloudflare Trace (`chatgpt.com/cdn-cgi/trace`), определяя точную страну (`loc`) и дата-центр (`colo`);
- **Anthropic Claude**: проверяет статус Claude через Cloudflare Trace (`claude.ai`);
- **Perplexity / Cursor**: проверяет доступность через шлюз Perplexity;
- **IP Info**: определяет провайдера, город и страну внешнего адреса.

Диагностика автоматически выполняется перед установкой, а также доступна отдельным пунктом **`5) Тест нейросетей`** в главном меню для быстрой проверки любого прокси.

## 🔄 Удаление и откат

В главном меню скрипта предусмотрен пункт **`6) Удалить прокси`**. Он в один клик:
- Удаляет созданные исходящие подключения и правила из `3x-ui`;
- Очищает таблицы `iptables`, `ipset` и удаляет службы `sing-box` и `amnezia-ai-proxy`;
- Удаляет добавленные алиасы из `~/.bashrc`;
- Возвращает сервер в исходное состояние.
